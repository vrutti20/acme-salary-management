# Demo video script (about 3 minutes, Loom)

1. **0:00 The problem (15 s).** "HR manages 10,000 salaries in Excel. This replaces that and answers how we pay people."
2. **0:15 Employees (45 s).** Search a name, filter by country and department, sort by USD salary, change page size. Mention server-side pagination on 10,000 rows.
3. **1:00 Add / edit (30 s).** Add an employee with a duplicate email to show the validation error, fix it, save. Edit a salary. Delete with confirmation.
4. **1:30 Insights (60 s).** Pay by country (median vs average), job title chart filtered by country (same role across countries), department payroll, distribution.
5. **2:30 Engineering (30 s).** Show the repo: commit history, `docs/`, run `npm test` in backend and frontend (fast, deterministic). Mention what was left out on purpose and why.
6. **3:00 Close.** Live URL and what you would do next (auth, salary history, persistent DB).
